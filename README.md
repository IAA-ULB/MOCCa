#### What is Tantalus?

Tantalus is a mean-field code, representing the single-particle wavefunctions on a Lagrange mesh, written in FORTRAN.

#### What is Hephaestos?

Hephaestos is a (collection of) Python modules/scripts that partially writes (parts of) the FORTRAN source code for Tantalus.
